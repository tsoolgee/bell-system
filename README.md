# מערכת ניהול צלצולים

אפליקציית Windows להפעלה אוטומטית של צלצולי בית ספר / תלמוד תורה, לפי לוח זמנים
שבועי, עם השבתה אוטומטית בשבתות ובחגים.

המערכת רצה ברקע במגש המערכת ומצלצלת לבד — אין צורך לפתוח דפדפן או ללחוץ על שום
דבר. **כל החישובים מקומיים: אין תלות באינטרנט.**

## התקנה

הורידו את `BellSystem.exe` והריצו. אין התקנה ואין תלויות.

בהפעלה הראשונה נוצרים:

```
C:\ProgramData\BellSystem\config.json   ההגדרות והצלצולים
C:\ProgramData\BellSystem\sounds\       קבצי הצליל
C:\ProgramData\BellSystem\bells.log     יומן פעילות
```

וכן לוח צלצולים לדוגמה שאפשר לערוך או למחוק. תצורה שנשמרה בגרסה ישנה תחת
`%APPDATA%` מועברת אוטומטית בהפעלה הראשונה.

**את ההרצה הראשונה כדאי לעשות כמנהל** (לחיצה ימנית ← „הפעל כמנהל"). זה מה
שמאפשר לשתף את ההגדרות בין כל משתמשי המחשב ולרשום את ההפעלה האוטומטית לכולם.
בלי זה המערכת עובדת, אבל רק עבור המשתמש שהתקין אותה — והממשק אומר זאת במפורש.

## כמה משתמשים על אותו מחשב

מוסד שבו גם המנהל וגם המזכיר מתחברים לאותו מחשב הוא המקרה הרגיל, לא חריג.
שלושה דברים נדרשים כדי שזה יעבוד, וכולם מטופלים:

| מה | איך |
| --- | --- |
| הגדרות משותפות | `C:\ProgramData\BellSystem` ולא בפרופיל האישי; הרשאת Modify ניתנת לקבוצת Users בהתקנה |
| המערכת עולה לכל מי שמתחבר | `HKLM\...\Run` כשמריצים כמנהל, אחרת `HKCU` למשתמש הנוכחי בלבד |
| מי מצלצל כשמחליפים משתמש | רק המופע שיושב מול המסך |

הסעיף האחרון אינו קוסמטי: **Windows אינו מנתב שמע לסשן מנותק.** אחרי „החלפת
משתמש" המופע הקודם ממשיך לרוץ, אבל שום צליל ממנו לא מגיע לרמקולים. לכן כל מופע
בודק את סשן הקונסולה ורק ההוא מצלצל — ומופע שאינו פעיל גם **אינו** מסמן את
הצלצול כאילו הופעל, אחרת הוא היה נבלע בין שני המופעים.

מכיוון שכל המופעים חולקים קובץ הגדרות אחד, כל אחד טוען אותו מחדש כשהוא משתנה,
כך ששינוי שהמזכיר עושה נכנס לתוקף אצל המופע שמצלצל תוך שנייה.

מסך **הגדרות ← כמה משתמשים במחשב** מציג את שלושת הסעיפים ומתריע על כל אחד
שאינו מוגדר נכון.

## מנגנון ההחלטה

לפני כל צלצול המערכת עוברת על הבדיקות לפי הסדר. די בכישלון אחד כדי שהצלצול
לא יושמע:

```
המערכת מופעלת?  →  אין השתקה ידנית?  →  לא בתוך שבת?
   →  לא בתוך יום טוב?  →  לא חג/חופשה?  →  הצלצול פעיל?  →  השמעה
```

כך שגם אם הוגדר בטעות צלצול בשעה אסורה — הוא לא יושמע.

### חישוב שבת ויום טוב

לא לפי "יום שבת" בלוח, אלא לפי זמן אמיתי:

* **כניסה** — שקיעה של ערב שבת פחות דקות הדלקת הנרות (ברירת מחדל 40 בירושלים).
* **יציאה** — שקיעה של מוצאי שבת ועוד דקות (ברירת מחדל 42), או לפי מעלות מתחת
  לאופק.

לכן צלצול שמוגדר ליום שישי ב־18:00 יפעל, וצלצול ב־18:45 לא יפעל אם השבת כבר
נכנסה. אותו חישוב חל על ימים טובים, וגם על רצף של יום טוב הסמוך לשבת.

השקיעה מחושבת באלגוריתם NOAA לפי קו הרוחב והאורך של המוסד. אין קריאות רשת.

### חגים

| ברירת מחדל מושבת | ברירת מחדל פעיל |
| --- | --- |
| ראש השנה, יום כיפור, סוכות, שמיני עצרת, פסח, שבועות | חנוכה, פורים, תעניות |
| חול המועד פסח וסוכות | ל״ג בעומר, ט״ו בשבט, ימי זיכרון ועצמאות |

כל דגל ניתן לשינוי במסך "חגים והשבתות". בנוסף אפשר להוסיף השבתות ידניות —
בתאריך לועזי (חד־פעמי) או בתאריך עברי (חוזר כל שנה, למשל חופשת חנוכה).

מסך זה כולל תצוגה מקדימה של 30 יום קדימה, כדי לוודא שהמערכת מחליטה כמצופה.

## התקן הפלט

**הגדרות ← שמע והפעלה ← התקן הפלט לצלצולים.**

הצלצולים יוצאים להתקן שנבחר כאן, **בלי קשר לברירת המחדל של Windows**. אפשר
לחבר אוזניות או להעביר את שאר המחשב למקום אחר — הצלצולים ימשיכו לצאת לאן
שהוגדר. זו הסיבה שמנוע השמע הוא SDL ולא MCI: MCI מנגן רק לברירת המחדל.

השארת השדה על „ברירת המחדל של Windows" תקינה לגמרי, והיא הבחירה הנכונה כשרוצים
שהצלצולים ילכו לאן שכל שאר המחשב הולך.

אם ההתקן שנבחר אינו זמין (נותק, שונה שמו, או תפוס בשימוש בלעדי), המערכת
**עדיין מצלצלת** — בברירת המחדל — ומציגה שהיא נפלה אליה. עדיף צלצול במקום הלא
נכון מאשר שקט.

### „בדיקת שמע"

מנגנת צלצול **ומודדת את הפלט האמיתי** בנקודת הקצה, כך שהיא מבדילה בין
„ניגנתי" לבין „יצא צליל". שלוש תשובות אפשריות:

| תשובה | פירוש |
| --- | --- |
| נמדד פלט שמע | הכול תקין. אם לא שומעים — הרמקולים או החיבור |
| האות מגיע אבל ההתקן מושתק / בעוצמה 0 | פתחו את עוצמת ההתקן במיקסר של Windows |
| לא נמדד שום פלט | הצליל לא הגיע להתקן בכלל |

**התקן וירטואלי אינו תקלה.** כבל כמו VB-Audio Cable או VoiceMeeter הוא לגיטימי
לחלוטין — למשל במחשב שנשלט מרחוק, שבו הצליל אמור להגיע למאזין ולא לחדר. המערכת
מציינת זאת ולא מתריעה עליו.

היא כן מתריעה על מה שבאמת משתיק צלצול: התקן מושתק, עוצמת התקן 0, או התקן שנבחר
ואינו זמין. אם התקן ברירת המחדל *בטעות* אינו הרמקולים, אפשר להצמיד את הרמקולים
כאן בלי לשנות שום הגדרה של Windows.

האבחון דורש `pycaw`, ובחירת ההתקן דורשת `pygame`. בלעדיהם המערכת עובדת רגיל,
עם MCI ולהתקן ברירת המחדל בלבד.

## כרוז מוקלט

במסך "ספריית צלילים" אפשר להקליד טקסט והמערכת תהפוך אותו להודעה קולית, שנשמרת
כצליל רגיל — כלומר אפשר לשבץ אותה בכל צלצול בלוח, למשל "ההפסקה הסתיימה" ב־10:05.

שני מקורות קול:

| מקור | אינטרנט | מפתח | עברית |
| --- | --- | --- | --- |
| **Gemini** | נדרש בזמן היצירה בלבד | מפתח API של Google AI Studio | קול טבעי |
| **Windows** | לא נדרש | לא נדרש | רק אם מותקן קול עברי |

ברוב מחשבי Windows מותקן קול אנגלי בלבד, ולכן להודעה בעברית צריך Gemini. אפשר
להתקין קול עברי דרך *הגדרות ← שעה ושפה ← דיבור*, ואז גם המסלול האופליין יעבוד.

**פרטיות:** המפתח נשמר ב־`config.json` שבמחשב בלבד, אינו נכלל בקובץ הגיבוי,
והטקסט נשלח ל־Google רק בלחיצה על "צור כרוז". אחרי היצירה הקובץ מקומי, והצלצול
עובד גם בלי אינטרנט.

ההקלטה עוברת נרמול לפי RMS עם דחיסה רכה, כדי שתישמע מעל רעש של כיתה.

## פיתוח

```bash
pip install -r requirements.txt
python run.py
```

בדיקות:

```bash
python tests/t_engine.py          # מנוע ההחלטה - לא דורש שרת
python tests/t_audio.py           # נגן השמע בדפוס התהליכונים של האפליקציה
python tests/t_tts.py             # כרוז (מסלול Gemini רק אם הוגדר GEMINI_API_KEY)
python tests/t_multiuser.py       # כמה משתמשי Windows על אותו מחשב
python tests/t_upgrade.py         # שדרוג גרסה לא נוגע בהגדרות
python run.py --no-tray &         # ואז, מול שרת רץ:
python tests/t_api.py 8730
python tests/t_keepalive.py 8730
```

בנייה:

```bash
pip install -r requirements-build.txt
python build.py
```

דחיפת תג `v*` מריצה את הבדיקות, בונה EXE ומפרסמת Release.
